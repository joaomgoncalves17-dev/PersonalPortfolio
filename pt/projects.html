Projetos

Projetos de laboratório que reproduzem o trabalho de uma equipa de infraestrutura. Os planeados ficam prontos até ao início do estágio, em janeiro de 2027, e cada um é publicado com a documentação.

01 Concluído

Domínio híbrido Windows e Linux

Rede de uma pequena empresa montada de raiz, com Active Directory, servidores Linux e um plano de recuperação testado.

  • Windows Server
  • Active Directory
  • Debian
  • Samba
  • Backups

Objetivo

Simular a infraestrutura de uma pequena empresa e conseguir recuperá-la depois de uma falha.

O que inclui

  • Controlador de domínio Windows Server com DNS e DHCP
  • Unidades organizacionais, grupos e políticas de grupo por departamento
  • Servidor Linux com partilhas de ficheiros e servidor web
  • Cópias de segurança automáticas e teste de restauro completo

O que fica documentado

  • Diagrama da rede
  • Plano de recuperação escrito
  • Lista de GPO aplicadas
02 Planeado

Servidor Linux com hardening a alojar este site

Este portfólio a correr num servidor Debian configurado por mim, exposto à internet só com o necessário.

  • Debian
  • OpenSSH
  • nftables
  • fail2ban
  • Nginx
  • Let's Encrypt
  • Lynis

Objetivo

Pôr um serviço real online com uma superfície de ataque pequena, conhecida e documentada.

O que inclui

  • Debian num VPS, com utilizador de administração e sudo
  • SSH só com chaves e sem login de root
  • Firewall nftables só com as portas 22, 80 e 443, e fail2ban no SSH
  • Atualizações de segurança automáticas com unattended-upgrades
  • Nginx com HTTPS da Let's Encrypt e renovação automática
  • Auditoria com Lynis antes e depois, para medir a diferença

O que fica documentado

  • Checklist de hardening com o motivo de cada alteração
  • Relatório Lynis antes e depois
  • Configurações num repositório Git
03 Planeado

Kit de manutenção em Bash

Scripts Bash para as verificações diárias e as cópias de segurança do servidor deste site, corridos por timers do systemd.

  • Bash
  • systemd
  • rsync
  • ShellCheck
  • Git

Objetivo

Trocar a verificação manual por scripts que correm sozinhos e só avisam quando algo está mal.

O que inclui

  • Relatório diário: disco, memória, serviços falhados e atualizações pendentes, enviado por email
  • Backup com rsync de /etc e do site, com rotação
  • Teste de restauro mensal, com o tempo registado
  • Timers do systemd em vez de cron, com registos no journal
  • Scripts validados com ShellCheck, com ajuda --help e modo --dry-run

O que fica documentado

  • Repositório Git com README
  • Exemplo de relatório
  • Registo dos testes de restauro
04 Planeado

Microsoft 365 e Entra ID para uma pequena empresa

Um tenant de teste do Microsoft 365 configurado como se fosse de uma empresa de 10 pessoas: contas, licenças, MFA e um portátil gerido pelo Intune.

  • Microsoft 365
  • Entra ID
  • Intune
  • Exchange Online
  • PowerShell

Objetivo

Praticar a administração cloud que aparece em quase todos os anúncios para sysadmin júnior, com as decisões documentadas.

O que inclui

  • Utilizadores e grupos por departamento, com licenças atribuídas por grupo
  • MFA para todos e acesso condicional para as contas de administração
  • Máquina virtual Windows 11 inscrita no Intune, com políticas de conformidade
  • Procedimento de entrada e saída de colaboradores: criar conta, bloquear acesso, converter caixa de correio

O que fica documentado

  • Procedimento de entrada e saída passo a passo
  • Lista de políticas com o motivo de cada uma
  • Capturas da configuração
