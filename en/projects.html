Projects

Lab projects that reproduce the work of an infrastructure team. The planned ones will be finished before my internship starts in January 2027, and each is published with its documentation.

01 Completed

Hybrid Windows and Linux domain

A small-business network built from scratch, with Active Directory, Linux servers and a tested recovery plan.

  • Windows Server
  • Active Directory
  • Debian
  • Samba
  • Backups

Goal

Simulate a small company's infrastructure and be able to recover it after a failure.

What it covers

  • Windows Server domain controller with DNS and DHCP
  • Organisational units, groups and Group Policy per department
  • Linux server with file shares and a web server
  • Automated backups and a full restore test

What gets documented

  • Network diagram
  • Written recovery plan
  • List of applied GPOs
02 Planned

Hardened Linux server hosting this site

This portfolio running on a Debian server I configured myself, exposed to the internet with only what it needs.

  • Debian
  • OpenSSH
  • nftables
  • fail2ban
  • Nginx
  • Let's Encrypt
  • Lynis

Goal

Put a real service online with an attack surface that is small, known and documented.

What it covers

  • Debian on a VPS, with an admin user and sudo
  • Key-only SSH and no root login
  • nftables firewall allowing only ports 22, 80 and 443, with fail2ban on SSH
  • Automatic security updates with unattended-upgrades
  • Nginx with Let's Encrypt HTTPS and automatic renewal
  • Lynis audit before and after, to measure the difference

What gets documented

  • Hardening checklist with the reason for each change
  • Lynis report before and after
  • Configuration in a Git repository
03 Planned

Bash maintenance toolkit

Bash scripts for the daily checks and backups of the server behind this site, run by systemd timers.

  • Bash
  • systemd
  • rsync
  • ShellCheck
  • Git

Goal

Replace manual checks with scripts that run on their own and only speak up when something is wrong.

What it covers

  • Daily report by email: disk, memory, failed services and pending updates
  • rsync backup of /etc and the site, with rotation
  • Monthly restore test, with the time recorded
  • systemd timers instead of cron, with logs in the journal
  • Scripts checked with ShellCheck, with --help and a --dry-run mode

What gets documented

  • Git repository with README
  • Sample report
  • Restore test log
04 Planned

Microsoft 365 and Entra ID for a small business

A Microsoft 365 test tenant set up as if for a 10-person company: accounts, licences, MFA and a laptop managed by Intune.

  • Microsoft 365
  • Entra ID
  • Intune
  • Exchange Online
  • PowerShell

Goal

Practise the cloud administration that appears in almost every junior sysadmin job ad, with the decisions documented.

What it covers

  • Users and groups per department, with group-based licensing
  • MFA for everyone and Conditional Access for admin accounts
  • Windows 11 virtual machine enrolled in Intune, with compliance policies
  • Onboarding and offboarding procedure: create the account, block access, convert the mailbox

What gets documented

  • Step-by-step onboarding and offboarding procedure
  • List of policies with the reason for each
  • Configuration screenshots
